# simple-ids-creator

Графическое приложение для генерации IDS-файлов из CSV- и Excel-таблиц.

Проект читает таблицу требований, группирует строки по IFC-классам и сохраняет результат в формате IDS через `ifctester`.

## Возможности

- загрузка одной или нескольких таблиц `CSV`, `XLSX`, `XLS`, `XLSM`, `XLSB`;
- генерация отдельного `.ids` файла для каждой таблицы;
- создание примера Excel-шаблона прямо из интерфейса;
- файловое логирование в `log/app.log`.

## Требования

- Python `3.13` или новее;
- зависимости из `pyproject.toml`:
  - `ifcopenshell`
  - `ifctester`
  - `pandas[excel]`

## Установка

Если используется `uv`, зависимости можно установить стандартной командой:

```bash
uv sync
```

Если `uv` не используется, установите зависимости любым привычным способом для вашего окружения Python 3.13.

## Запуск

Приложение запускается из корня репозитория:

```bash
python main.py
```

## Как работает генерация

1. Выберите одну или несколько таблиц требований.
2. Выберите папку для сохранения IDS.
3. Нажмите `Сгенерировать IDS`.

Имена выходных файлов формируются по имени исходной таблицы. Например, для `requirements.xlsx` будет создан `requirements.ids`.

## Формат входной таблицы

Примерная структура таблицы:

- первая строка содержит заголовок документа;
- вторая строка содержит шапку;
- начиная с третьей строки идут требования.

Ожидаемые колонки:

- `№`
- `Имя атрибута`
- `Тип значения`
- `IFC property set (опционально)`
- далее идут колонки IFC-классов, например `IfcWall`, `IfcDoor`, `IfcWindow`

Значения в колонках IFC-классов считаются отметкой требования, если ячейка содержит одно из значений:

- `1`
- `1.0`
- `true`
- `yes`
- `x`
- `да`

Если `IFC property set` не заполнен, используется значение по умолчанию `Параметры`.

## Пример шаблона

В интерфейсе есть кнопка `Сохранить пример таблицы`. Она создаёт `.xlsx` файл с готовой структурой, которую можно взять за основу.

## Результат

Для каждой подходящей строки таблицы создаётся IDS-спецификация по IFC-классу. В документ по умолчанию включаются версии:

- `IFC2X3`
- `IFC4`
- `IFC4X3_ADD2`

## Логирование

При запуске и генерации создаётся лог-файл `log/app.log`. Он содержит служебные сообщения, предупреждения и ошибки разбора таблиц.

## Структура проекта

- `main.py` — точка входа;
- `simple_ids_creator/interface.py` — Tkinter-интерфейс;
- `simple_ids_creator/ids_builder.py` — чтение таблиц и сборка IDS;
- `simple_ids_creator/logger.py` — файловое логирование;
- `simple_ids_creator/utils.py` — вспомогательные функции.
